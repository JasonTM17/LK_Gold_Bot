# Changelog

All notable changes to this project are documented here.

## Unreleased

- Added repository metadata, CI, issue templates, and project documentation.
- Expanded setup, deployment, security, and troubleshooting guidance.
- Improved tests and maintainability around parsing/configuration helpers.

## 1.0.0 - 2026-08-29

- Refactored the project into a safe personal Telegram assistant.
- Added `.env`-based configuration and `.env.example`.
- Added SQLite usage tracking and admin commands.
- Added Locket public-link parsing helpers.
- Added optional NextDNS personal profile creation.
- Added Windows and Linux run scripts.
- Added initial unit tests for Locket parsing.
