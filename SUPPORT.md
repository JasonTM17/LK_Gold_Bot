# Support

This is a personal project, so support is best-effort.

## Before asking for help

Please check:

1. `README.md`
2. `docs/CONFIGURATION.md`
3. `docs/TROUBLESHOOTING.md`
4. Existing GitHub issues

## Useful information to include

- Operating system and Python version.
- The command you ran.
- The exact error message.
- Whether `.env` contains `BOT_TOKEN` and `ADMIN_ID`.
- Whether tests pass locally.

Never share real bot tokens, API keys, OTP codes, or database files.

## Scope

Good support topics:

- Installing dependencies.
- Running the Telegram bot.
- Understanding admin commands.
- Fixing local configuration issues.
- Improving docs/tests/CI.

Out-of-scope topics:

- Bypassing paid features.
- Accessing someone else's account.
- Collecting secrets or private data.
- Automating behavior that violates third-party terms.
